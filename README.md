# Python Basics Lessons

Twenty beginner lessons, in order. Each file has the explanation, practice exercises, common mistakes, a recap and a challenge, followed by a complete example program.

Start with `lesson_01_getting_started.md` and work through to `lesson_20_glossary_and_practice.md`.

To run an example, copy its code block into a file named `example.py` and run `python example.py` in a terminal.
