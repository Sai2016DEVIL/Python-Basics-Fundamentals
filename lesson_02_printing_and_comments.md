# Lesson 2: Printing and Comments

## print()
`print()` shows text or values on the screen. Put what you want to show between the brackets.

    print("Hello")

Text in quotation marks is called a string. You can use single or double quotes.

## Printing several items
Separate items with commas. Python puts a space between them.

    print("Age:", 10)

## Comments
A comment starts with `#`. Python ignores everything after it on that line. Comments explain code to people reading it.

    # This line is ignored by Python
    print("This line runs")

## Practice exercises
1. Print your favourite colour.
2. Print two lines by using two `print()` calls.
3. Print a sentence that mixes words and a number, such as `print("I have", 3, "pets")`.

## Common beginner mistakes
- Forgetting the closing quotation mark, which causes a SyntaxError.
- Writing `Print` with a capital P. Python is case-sensitive.
- Expecting a comment to run. Comments never run.

## Recap
- `print()` displays output.
- `#` starts a comment.

## Challenge
Print a small picture made of text, such as a simple house using `print()` on several lines.

## Example code

```python
# Lesson 2 example: printing and comments

# Print a simple message
print("Printing is how programs talk to us.")

# Print several values separated by commas
print("My name is", "Sam", "and I am", 10, "years old.")

# A comment on its own line is ignored
print("Comments do not run.")  # This comment sits at the end of a line
```
