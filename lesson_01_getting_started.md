# Lesson 1: Getting Started

## What is Python?
Python is a programming language. You write instructions in plain text, and the computer follows them in order. Python is popular because its instructions read almost like English.

## Running a .py file
A file that ends in `.py` contains Python code. To run it, open a terminal in the same folder and type:

    python example.py

On some systems you may need `python3` or `py` instead.

## Syntax
Syntax is the set of rules for writing valid code. Python is strict about spelling, capital letters, and punctuation.

## Practice exercises
1. Create a file called `hello.py` and make it print any sentence.
2. Run `hello.py` from the terminal and check the output.
3. Change the sentence, save, and run again.

## Common beginner mistakes
- Forgetting to save the file before running it.
- Running the command from the wrong folder. Use `cd` to move to the right folder.
- Typing `Python` with a capital P in the terminal. The command is lowercase `python`.

## Recap
- Python code lives in `.py` files.
- You run a file with `python filename.py`.

## Challenge
Write a program that prints three lines of text, one after another.
